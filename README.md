### 💕研究方向


研究聚焦于心理测量与统计模型的算法开发，及其在心理健康领域的应用，主要通过密集追踪、动态系统分析、多模态评估、机器学习等方法揭示个体维持健康行为、应对应激压力、罹患情绪障碍的预测因子和内在发生机制。

**计量心理学**：发展针对追踪和密集追踪数据的统计模型；探索多模态数据的采集处理融合和解释方法。

**健康心理学**：从动态系统视角解释健康行为过程，包括压力、疲劳、情绪、饮食、数字生活等；采用多模态机器学习预测预警健康风险。
